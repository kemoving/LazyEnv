About LazyEnv

A cross-platform, recoverable, zero-pollution dev environment configurator.

What is LazyEnv?

LazyEnv is a questionnaire-style development environment configuration tool for Windows. It automates the detection, installation, and management of 40+ development tools — all powered by winget under the hood. No manual PATH wrestling, no leftover pollution, and every change can be rolled back.
